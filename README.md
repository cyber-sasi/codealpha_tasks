\### Task 4 — Network Intrusion Detection System



A Python-based Network Intrusion Detection System (NIDS) designed for authorized network monitoring and defensive security analysis.



\*\*Key Features:\*\*



\- Network traffic monitoring

\- Configurable detection rules

\- Suspicious traffic detection

\- Alert generation

\- Severity classification

\- SQLite-based alert storage

\- CSV and JSON alert export

\- Traffic statistics

\- Logical response mechanism

\- Safe synthetic demonstration mode

\- Automated testing



\*\*Detection Rules:\*\*



\- Possible TCP Port Scan

\- Possible TCP Connection Flood

\- Possible ICMP Anomaly

\- Repeated Traffic Pattern Anomaly



\*\*Technologies:\*\*



\- Python

\- Scapy

\- SQLite

\- Pytest
